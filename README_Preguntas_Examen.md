Examen 1 Parcial DAM

Parte 1 Teoría 

1. React Native es un framework de código abierto que nos permite la creación de Aplicaciónes Móviles Multiplataforma, ya sea para Android o iOS.
   
2. Una aplicación móvil es un software diseñado para dispositivos móviles como lo puede ser un celular o una tablet y estas nos facilitan tareas de la vida cotidiana, y 2 aplicaciones que uso en mi día a día son, X para mantenerme al tanto de lo que pasa alrededor del mundo. así como tambien Netflix en la que puedo ver series y películas.
   
3. Las aplicaciones nativas son propias de un solo Sistema Operativo, el cual puede ser Android o iOS. Las aplicaciones hibridas permiten un código único base pero son compatibles con distintos Sistemas Operativos. Las aplicaciones web se comportan como si fueran aplicaciones móviles pueden instalarse en la pantalla de inicio y funcionar offline.
   
4. View: Sirve para organizar los elementos de la pantalla, funciona como contenedor para organizar mejor los componentes de la App.
Text: Sirve para escribir texto dentro de la aplicación. Image: Sirve para importar imagenes y poder utilizarlas en la App. TextInput: Permite que el usuario pueda ingresar texto dentro de la App.

5. UseState es una función de ReactNative y nos sirve para poder asignar un estado a un componente y mediante este poder controlarlo para que podamos asignarle cambios. UseSate se puede utilizar por ejemplo para cuando queremos control del btn de seguir en alguna red social, y que este cambie si es qeu sigue o no al usuario.

6. a) Porque nos ayudan a controlar los estados de los componentes y con esto poder cambiar lo que ve el usuario en la pantalla. b) si una App no tuviera estados dinámicos, seria una App estatica en la que los componentes no puedan cambiar en base a acciones realizadas por el usuario. c) Un ejemplo en donde usaría estados es en el contador de likes de alguna publicación de una red social.
